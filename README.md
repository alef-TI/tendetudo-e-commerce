# TendeTudo E-commerce

Projeto acadêmico de uma plataforma de comércio eletrônico
desenvolvida com Vue.

## Requisitos
- Node.js
- npm

## Instalação
cd frontend
npm install

# Acessar a pasta do frontend
cd frontend

# Instalar as dependências
npm install

# Executar o ambiente de desenvolvimento
npm run serve

# Gerar a versão de produção
npm run build

# Executar a análise de código, caso o script esteja configurado
npm run lint
